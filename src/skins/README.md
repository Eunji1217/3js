# 스킨 폴더

이 폴더에 `.glb` 또는 `.fbx` 캐릭터 파일을 넣으면 게임의 스킨 목록에 자동으로 나타납니다 (파일 이름이 스킨 이름).

- Mixamo 뼈 이름(`mixamorig:Hips` 등, 또는 `Hips` 등)을 쓰는 사람형 모델이면 됩니다.
- 모델에 `Idle` / `Walk` / `Run` 애니메이션이 들어 있으면 그대로 쓰고, 없으면 Soldier 의 애니메이션을 자동으로 옮겨서 씁니다.
- Adobe Mixamo(https://www.mixamo.com)에서 캐릭터를 고른 뒤 **Download → Format: FBX Binary, Skin: With Skin** 으로 받은 파일을 그대로 넣을 수 있습니다.
